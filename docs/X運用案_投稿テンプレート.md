## 2. 投稿の3本柱

### ① 速報・短観（毎日〜数日に1回）
相場・개別銘柄の「今」をキャラの声で。最も伸びやすい。

### ② 解説・気づき（週2〜3回）
投資の考え方を1ポスト1テーマで。ブログ記事の「さわり」を出して続きへ誘導。

### ③ 世界観・キャラ（不定期・箸休め）
キャラ同士の掛け合い。ファン化・拡散の起点。バズ狙い。

## 5. 投稿頻度・時間帯

| タイミング | 内容 | 理由 |
|---|---|---|
| **平日 朝7:30〜8:30** | 速報・短観 | 通勤中の投資クラスタが活発 |
| **平日 12:00〜13:00** | 解説・気づき | 昼休みの閲覧ピーク |
| **平日 21:00〜23:00** | 世界観・キャラ・ブログ誘導 | 最も伸びる時間帯。新記事告知もここ |
| **決算・TOB発表時** | 即・速報 | 鮮度が命。指名検索とセットで伸びる |

- 目安：**1日1〜3ポスト**から無理なく。毎日続ける方が頻度より重要
- 新記事公開時は「型A/B」で必ず告知 → 数時間後に角度を変えて再告知

## 6. コンプラ安全な言い回し（NG / OK 対照）

| ❌ NG（助言・断定・約束） | ⭕ OK（観察・記録・意見） |
|---|---|
| この株は買いです | 私はこの株に注目しています／保有しています |
| 必ず上がる／鉄板 | 上がる余地があると考えています |
| 今すぐ買うべき | 私ならこの水準で検討します |
| 〇〇円まで上がります | 期待株価の試算は〇〇円（あくまで参考値） |
| 損はさせません | 投資は自己責任でお願いします |

- 銘柄に触れる投稿には、定期的に「※投資助言ではありません」を添える
- 数字（期待株価・利回り）は必ず「試算・参考値」と明記

## 7. ハッシュタグ・運用Tips

- タグは付けすぎない。**1〜2個**まで（例：`#日本株` `#割安株` `#バリュー株` `#TOB`）
- 銘柄コードは「$」より日本では `(7868)` 表記＋社名が拾われやすい
- リプ・引用で他の投資家と絡む（一方通行にしない）
- 伸びたポストは数日後にブログ誘導版で再利用
- インプレ乞食・煽り・他者銘柄disはしない（信頼が資産）

## 8. 立ち上げ最初の2週間プラン

| Day | やること |
|---|---|
| 1 | プロフィール・アイコン・ヘッダー設定、固定ポスト投稿 |
| 2-3 | 自己紹介スレッド（投資遍歴・スタンス）、世界観紹介 |
| 4-7 | キャラ投稿で世界観を浸透（各キャラ1回ずつ） |
| 8-14 | 既存ブログ記事を「型A/B」で1日1本ずつ告知（PER・借金・効率的市場・銘柄紹介…） |
| 以降 | 速報＋解説＋誘導のローテーションを定着 |

ストック記事が20本以上あるので、**最初の2〜3週間は告知ネタに困らない**のが強み。
