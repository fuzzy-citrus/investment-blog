## 話数のルール（2026-09-30 決定）

**第N話は「公開した順」の通し番号。** `src/data/comics.ts` の `episode` に持たせてある。

- 新作を公開するとき … `episode` に**既存の最大+1**を入れ、配列の末尾に足す
- **公開済みの話の `episode` は変えない。** あとから連載の並びを変えたくなっても番号は据え置き
- 一覧と個別ページの表示順はページ側で `episode` を見て並べている（一覧は新しい順）。配列の位置は表示にも番号にも影響しない
