# 第1話「80万円の財布」

**元記事slug：`value-concept`**
**伝えること：** 株価の安さではなく、中身と値札の差を見る

## 前編「勘違い」

**1コマ目**
- 絵：屋台の並ぶ市場。日向が「1株100円」の大きな値札が付いた、ぺらぺらに薄い財布を両手で掲げ、目を輝かせている。河内は隣の棚で虫眼鏡を構え、別の財布を覗き込んでいる。
- 日向「100円！ 世界一安いっす！」
- 河内「中は、見ましたか」

**2コマ目**
- 絵：河内が日向の財布を開いて逆さに振っている。落ちてくるのはレシート1枚と小銭が数枚だけ。日向の笑顔が固まる。
- 河内「100円の値札に、中身は30円です」
- 河内「安いのではなく、それが値段です」

**3コマ目**
- 絵：日向が店じゅうの安い財布をかき集め、腕いっぱいに抱えている。どれもぺったんこ。背景の棚には「1株50円」「1株20円」の札が並ぶ。
- 日向「じゃあ一番安いのを全部っす！」
- 河内「数を増やしても、中身は増えません」

**4コマ目（オチ）**
- 絵：引きの構図。ぺったんこの財布の山に日向が埋もれ、頭だけ出している。山の隙間からレシートが風に舞う。少し離れた棚で河内が、パンパンに膨らんだ財布をひとつだけ手に取っている。その値札は「80万」。財布の口からは札束の角がのぞく。立て札「値札ではなく、中身を見る」。
- 日向「……軽いっす」
- 河内「私はこれを1つ。中身、100万です」

**締めの一文：** 安い株ではなく、中身より安い株を買う。

## 後編「あるべき姿」

**1コマ目**
- 絵：カウンターの上に、河内が例の分厚い財布の中身を換金しやすい順に並べている。札束・権利書・有価証券の束に、それぞれ「現金」「土地」「投資有価証券」の小さな札。日向がメモ帳を構えている。
- 河内「換金できる順に、並べます」
- 日向「全部おカネに見えるっす」

**2コマ目**
- 絵：河内が権利書を電灯に透かして見ている。権利書の隅に「簿価 昭和45年」の判。壁には右肩上がりの地価の紙が貼ってある。
- 河内「帳簿の額と、売れる額は違います」
- 河内「土地は、買った年で止まっています」

**3コマ目**
- 絵：日向が財布の中から、小さな芽の出た鉢を見つけて驚いている。芽には「毎年10万」の札。枝先に小さなコインの実がひとつ。
- 日向「この芽、なんすか」
- 河内「稼ぐ力です。中身は毎年育ちます」

**4コマ目（オチ）**
- 絵：引き。「80万」の値札が付いた財布の前に、中身が「100万」と積み上がり、その上から芽が伸びて「+10万」の実をつけている。日向が口を開けて見上げる。河内は虫眼鏡をしまい、次の棚へ歩き出している。奥の棚には埃をかぶった財布がまだ並ぶ。立て札「100万の中身が、80万で売られている時に買う」。
- 日向「……値札のほうが、間違ってるっす」
- 河内「そういう日を、待ちます」

**締めの一文：** 100万の中身が80万で売られている時に買う。

**この話で学べること（記事下の3行）**
- 株価の絶対額ではなく、換金できる中身と値札の差を見る
- 帳簿の資産額と実際に売れる額は違う。昭和の簿価で止まった土地がある
- 中身が毎年育つ会社なら、待つ時間が味方になる

# 第2話「タダになった木」（構成）

**伝えること：** 元本を回収できるかで見る。回収したあとも実り続けるかは、堀で決まる

- 誤解：日向が「PER3倍の木」を見つけて大喜び。3年で元が取れると皮算用
- 説明：堀田が、その木は誰でも同じ場所に植えられる（真似される）商売だと示す
- 暴走：日向がPERの数字だけで木を買い集め、林にする。どの木も同じ品種で、隣に他人の同じ林ができている
- オチ：堀田の木は1本だけ。柵（堀）と水路に囲まれ、5年目に「苗代ぶん」の実を回収し終えて、その後も実り続けている。日向の林は実が付く前に隣の林と値下げ合戦になっている
- キー：PER5倍＝5年で元本回収／回収後は実質タダで果実が続く／ただし堀がないと5年後に稼げない

# 第3話「お宝には、客が来る」（構成）

**伝えること：** 中身が厚くて稼ぐ力もある会社は、放置し続けるのが難しい。ただし客待ちで買わない

- 誤解：日向が「誰も買ってないっす。やっぱりダメな会社なんじゃ」と不安になる
- 説明：待伏が、中身も稼ぐ力もある店に客が来ない状態は続きにくいと示す（TOB・MBO・物言う株主の3つの客）
- 乱入：🧘 オルカン教祖「来ない客を待つより、来ている店に並べばいいのでは」
- オチ：閉じた店の前に、ある朝ぬっと3人の客（スーツの人影・創業家の老人・拡声器を持つ人物）が同時に立っている。日向が驚く横で、待伏は**客が来る前から座っていた**。立て札「客を当てにして買わない。客が来ても困らない値段で買う」
- キー：カタリストは結果であって理由ではない（TOB期待では買わない）

# 第4話「値札を決めるのは、こっち」（構成）

**伝えること：** 買いは技術。入口を間違えなければ、最悪の幅が決まる

- 誤解：日向が「良い会社なら、いつ買っても同じっす」と、値札を見ずにレジへ走る
- 説明：沼田が、同じ会社でも買値で結果の幅が変わることを、物差しを当てて示す
- 暴走：日向が「良い会社リスト」を握りしめ、値札を全部めくらずに買い物かごへ入れ続ける
- オチ：🦞 守田がかごの前に立ち、はさみで「待った」。かごの底が抜けていて、値札だけがばらばら落ちている。立て札「買いは技術、売りは芸術」
- キー：エントリーを間違えなければ最悪のシナリオは抑えられる／売りの難しさは別の話として次に繋ぐ
