# キャラクター画像の運用

2026-09-25、ユーザーから「別の画像が混ざっている。Codexが作成した画像へ戻し、顔の見切れも直す」と指定。

## 正本
- 元画像: public/images/shared-cast-20260925/（デスクトップ共通素材フォルダの画像と対応）
- Web用: public/images/cast-web/。元画像を縦横640px以内に比例縮小したWebP。新しく描き直していない。
- 採用画像と顔の表示位置: src/data/castPortraits.mjs。この設定を11人共通の正本とする。
- アイコン表示: src/components/CastIcon.astro と src/styles/global.css。

## 表示ルール
- メンバー紹介は元絵の全身を object-fit: contain で表示。顔だけの丸抜き、画像の伸縮・反転・ホバー時の別絵への切替は行わない。
- 記事・組織図・トップページ・筆者紹介・サイドバーは同じ元絵を使う。
- 顔は画像ファイルを切り落とさず、CSSでキャラ別の範囲を表示。口先、耳、触角、頭頂部の余白を確保する。一律の中央切り抜きや丸抜きに戻さない。
- public/images/chars/ と旧numata-author画像は参照しない。過去素材そのものは削除しない。
- 未作成のライバルキャラは絵文字を維持し、別キャラの画像を代用しない。
- スマホでは紹介ページ・組織図・筆者紹介の横はみ出しを起こさない。

## 検証
- 123記事、3,145か所の話者アイコンを検査。古い画像参照・画像欠落・壊れた太字・下書き出力なし。
- 11人の画像対応と話者名・本文の維持を確認。
- パソコン幅と390px幅で紹介・会話・組織図を目視確認。
- markdownプラグインやcastPortraits設定を変更した際は npm run build -- --force を使い、Astroの古い記事キャッシュを残さない。通常のbuildだけでは古い画像HTMLが再利用されることがある。
- 並行作業によるdist競合を避け、今回は dist-cast-fix にビルドし、pagefindもその出力へ実行した。公開先はCloudflare Pagesのmaster。
