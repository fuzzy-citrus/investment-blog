## 🧑‍💼 それでもランクはA−で据え置く｜「前提の毀損」と「価格の下落」を秤にかける

## 🦞 掘り下げ｜「損出し」をしながら、保有は続けられるか

🦞**守田**「ここから、含み損を抱えている人向けの実務の話をする。<span class="t-blue">売りたくはない。でも含み損は出ている。このとき使えるのが損出しだ</span>」

> ・<strong>買い戻せば、保有は続けられる</strong>
> ・相殺しきれない損失は、<span class="t-blue">確定申告すれば3年間繰り越せる</span>

🦞**守田**「<span class="t-amber">つまり『含み損を、その年の税金を減らす道具に変える』作業だ</span>。<strong>ポジションを手放したくないなら、買い戻せばいい</strong>。——<span class="t-red">ただし、ここに初心者が必ず踏む地雷がある</span>」

### 🚨 最大の落とし穴｜同じ日に「現物で」買い戻すと、損が消える

🦉**夜見**「<span class="t-red">特定口座の取得単価は『総平均法に準ずる方法』で計算されます</span>。<strong>同じ日に売却と買付があると、その日の買付を含めた平均単価で譲渡原価が計算し直されます</strong>」

> ⚠️ **同日に現物を売って、現物で買い戻した場合（1,000株・取得3,000円・現値2,620円の例）**
> ・期待：<span class="t-green">売却で38万円の損失を確定 → 約7.7万円の還付</span>
> ・実際：<span class="t-red">同日買付が取得単価の計算に混ざり、確定する損失が大きく圧縮される</span>

🦞**守田**「<span class="t-amber">対策は単純だ。売却の翌営業日以降に買い戻す</span>。<strong>ただし、その1日が空くことで別のリスクを抱える——翌日に上がってしまえば、節税額より買い直しのコストのほうが大きくなる</strong>」

### 🧓 野村の本命｜信用を使えば、その1日を消せる

🧓**野村**「レバレッジ担当の野村じゃ。<span class="t-green">いま守田が言った『翌営業日まで待つ』——実は、待たずに済む方法がある</span>。<strong>信用取引を使えばよい</strong>」

> ・<strong>① 同日：現物を売却</strong>——<span class="t-green">損失が満額で確定する</span>

### 🧑‍💼 実例｜損出しは「守り」ではなく、攻めの道具になる

🧑‍💼**沼田**「ここからが、今年のうちの実感だ。<span class="t-green">損出しは、利益が厚い年ほど効く</span>。<strong>そして今年は、まさにその年だ</strong>」

🦉**夜見**「整理しますと、損出しの相殺先は2つあります。<span class="t-blue">①その年に実現した譲渡益 ②配当金（申告分離課税）</span>。<strong>特定口座（源泉徴収あり）で配当を受け入れる設定にしていれば、損失を確定した時点で、すでに徴収済みの税金が自動的に口座へ戻ってきます</strong>。<span class="t-amber">確定申告は不要です</span>」

🧑‍💼**沼田**「そこで発想を逆にする。<span class="t-red">『損が出たから仕方なく損出しする』のではない</span>。<strong>『損出しで枠を作ったから、利益のほうを動かせる』——こちらが本題だ</strong>」

> 🎯 **損出しで作った枠の、3つの使い道**
> ・<strong>① 目標株価に近づいた銘柄のスライス利確</strong>——<span class="t-green">本来なら20.315%引かれる利益を、損失と相殺して実質無税で確定できる</span>
> ・<strong>② 上がりすぎて比率が膨らんだ銘柄の縮小</strong>——<span class="t-blue">「税金がもったいない」という理由でリバランスを先送りしていたポジションを、コストなしで整理できる</span>
> ・<strong>③ 信用で安く仕込めた銘柄の現引き</strong>——<span class="t-amber">建玉を現物へ移して長期保有に切り替える。金利負担が消え、配当も配当所得として受け取れるようになる</span>

🐝**花岡**「高配当担当から②を補足します。<span class="t-amber">上がりすぎた銘柄を持ち続けるのは、実は『税金を払いたくないから』という理由であることが多い</span>。<strong>損出しの枠があれば、その心理的な足かせが外れます</strong>。<span class="t-green">含み益が厚い年ほど、この効果は大きくなる</span>」

🧓**野村**「③についてはわしから。<span class="t-blue">現引きそのものは譲渡ではないから、課税は発生せん</span>。<strong>だが信用のまま持っていると配当は『配当落調整金』として入り、これは税務上の譲渡損益扱いになる</strong>——<span class="t-green">つまり損出しの損失と、そのまま相殺できる</span>。<span class="t-amber">信用を使って長く持つ人にとって、損出しは毎年の恒例行事になりうるということじゃ</span>」

### 🐝 そして菱友のような一枚こそ、取得単価を下げる好機

🐝**花岡**「今回の菱友のように、<span class="t-green">長く持つつもりの銘柄が一時的な決算で下げたとき</span>——<strong>ここが取得単価を付け替える絶好の場面です</strong>」

🧑‍💼**沼田**「その通りだ。<span class="t-blue">だが『長く持つ銘柄』でやる場合、その繰り延べは実質的にかなり有利になる</span>」

> ・<span class="t-green">還付された税金は、今すぐ再投資できる</span>——<strong>その分だけ複利が早く回る</strong>
> ・<span class="t-blue">売らなければ、繰り延べた税は永久に払わずに済む</span>——<strong>「長く持てる銘柄」でやる意味はここにある</strong>
> ・<span class="t-amber">損失の繰越控除は3年で切れる。利益が厚い年に使い切るほうが、確実に価値になる</span>
> ・<span class="t-red">逆に「いずれ売る予定の銘柄」でやると、繰り延べ効果は小さい</span>

🦞**守田**「最後にもう一度、順序の話に戻す。<span class="t-red">①のスライス利確は、『目標株価に近づいた』という投資判断が先にあって初めて成立する</span>。<strong>『損出しの枠が余っているから、まだ上がる株を売る』——これは本末転倒だ</strong>。<span class="t-amber">枠は理由にならない。理由はいつも、価格と価値の関係のほうにある</span>」

### 🧑‍💼 最後に、順序を間違えないこと

🧑‍💼**沼田**「ここは強調しておく。<span class="t-red">損出しと買い増しは、まったく別の軸の話だ</span>」

> 🧭 **混ぜてはいけない2つの判断**
> ・<strong>損出し</strong>＝<span class="t-blue">税務上のテクニック</span>。「この銘柄を持ち続けるか」とは無関係に、今年の税金の話
> ・<strong>買い増し</strong>＝<span class="t-green">投資判断</span>。「今、新規にこの値段で買うか」だけで決める
> ・<span class="t-red">『損出しのついでに買い増そう』は、税務の都合で投資判断を歪めている</span>
> ・<strong>正しい順序は「持ち続ける価値があると判断した。ならば損出しで税金を取り戻しておく」</strong>

🧑‍💼**沼田**「<span class="t-green">今日の結論に照らせば、菱友は『堀は無傷、前提は2つ崩れたが価格がそれを吸収した、ランクはA−据え置き、売却はしない』だ</span>。<strong>その判断が先にあるから、損出しという手段が意味を持つ。順序が逆になった瞬間、税金のために不本意なポジションを持たされることになる</strong>」

## 買い方｜三分割、判定日は10月31日

🧑‍💼**沼田**「以上を踏まえて、行動を決める」

> 🧱 **三分割の設計**
> ・<strong>第1弾：現水準 2,600〜2,700円で1/3</strong>（<span class="t-blue">8月10日終値2,620円はこのレンジ内。PER9.3倍・利回り3.82%</span>）
> ・<strong>第2弾：10月31日の2Q決算後に1/3</strong>——<span class="t-red">ただし上期経常が21.5億円以上（通期進捗38%以上）で着地し、通期予想が据え置かれた場合のみ</span>。下回れば見送り
> ・<strong>第3弾：2,400円以下の押し目で1/3</strong>——<span class="t-amber">下方修正を伴わない需給要因の下落であれば実行。下方修正が原因なら実行せず、撤退基準の判定へ</span>
> ・<span class="t-red">日次出来高1.5〜7万株の薄商い。指値・複数日に分けた執行が必須</span>

🦞**守田**「<span class="t-amber">なぜ分割か。1四半期の数字だけでは『投資フェーズの一時的コスト』か『構造的なマージン低下』かを判別できないからだ</span>。<strong>判別材料が出るのは10月31日</strong>。<span class="t-blue">一方で『完全に確認してから買う』と、確認できた頃には株価は戻っている</span>。<strong>この不確実性を分割で引き受ける</strong>」

> 📅 **10月31日の2Q決算で確認する5項目**
> 1. <strong>上期経常が21.5億円を超えたか</strong>（<span class="t-red">最重要</span>。前年上期は22.6億／進捗40.3%）
> 2. <strong>2Q単独の営業利益率が12%以上に戻ったか</strong>（<span class="t-red">最重要</span>。前年2Q単独は13.5%。戻らなければ構造的マージン低下の証拠）
> 3. 通期予想が据え置かれたか、下方修正されたか
> 4. <span class="t-amber">実効税率が正常化したか</span>（1Qは40.2%。法定実効税率は約30〜31%で、大部分は期ズレか一過性の可能性が高い）
> 5. <strong>商材販売以外（SI・設計支援）の売上動向</strong>——<span class="t-red">コアが減っていれば堀の毀損を疑う</span>

## 🚪 撤退基準｜紹介記事に欠けていたもの

🦞**守田**「<span class="t-red">紹介記事には、リスクの一覧はあったが『何が起きたら降りるか』という行動基準がなかった</span>。<strong>今日、それを埋める</strong>」

| 撤退トリガー | 重み | 理由 |
|---|---|---|
| <strong>① 通期業績予想の下方修正</strong> | <span class="t-red">即時見直し</span> | 会社予想の達成が全計算の前提。崩れたらゼロベースで再計算 |
| <strong>② 通期営業利益率が10%を下回る</strong> | 高 | 26/3期12.7%→27/3期会予12.1%。10%割れは「高収益SIer」の根拠が消える |
| <strong>③ 商材以外（コアSI）の売上減少</strong> | 高 | <span class="t-red">三菱重工の発注そのものの減少＝堀の毀損。テーゼが完全に崩壊する</span> |
| ④ 減配または増配の停止 | 中 | 連続増配が途切れる＝経営が自ら「回復の目処が立たない」と認めたに等しい |
| ⑤ 上場維持基準への「適合」表明 | 中（逆説的） | <span class="t-amber">流通株式比率が基準を満たせばTOB期待の論拠が消滅する</span> |
| ⑥ 三菱重工の防衛部門の失速 | 低（現状） | 売上の大半を1社に依存する構造上の最大リスク |

🦞**守田**「<span class="t-amber">含み損を抱えた状態では、どんな悪材料も『もう織り込み済み』『一時的』と解釈したくなる</span>。<strong>判断が歪む前に、基準を書いておく。それが唯一の対策だ</strong>」

## まとめ｜ランクはA−据え置き。堀は無傷、前提は要修正、価格がそれを吸収した

🧑‍💼**沼田**「今日の再検証を、一枚に畳む」

| 論点 | 結論 |
|---|---|
| 堀（防衛・宇宙IT準独占） | <span class="t-green">無傷。減収の主因はIBM商材の転売で、三菱重工向けの開発・設計支援が減ったという開示はない</span> |
| 崩れた前提① | <span class="t-red">「会社予想は毎年上振れる」——1Q進捗13.8%（5年平均15.3%）が否定。紹介記事の中核ロジックだった</span> |
| 崩れた前提② | <span class="t-red">「賃上げは単価転嫁で相殺できる」——営業利益率8.6%→7.5%が反証。親子関係ゆえ転嫁力はむしろ制約される</span> |
| 訂正 | <span class="t-amber">DPS 92.5→97.5円、ROE「20%超」→18.9%、BPS約1,700→1,742.54円、会予EPS 290→282円。すべて楽観方向の誤りだった</span> |
| 下値論拠の格下げ | <span class="t-red">「手元資金102億＝時価総額の28%」はCF計算書上33億。預け金の性格が不明で、下値論拠としては弱い</span> |
| バリュエーション | <span class="t-green">PER9.3倍・PBR1.50倍・利回り3.82%。株価の下落幅が業績悪化幅を上回り、期待リターンはプラス40%→プラス48%へ改善</span> |
| <strong>ランク判定</strong> | <span class="t-green"><strong>A− 据え置き</strong></span>——<span class="t-blue">前提の毀損を、株価9.5%の下落が吸収したため</span>。<span class="t-red">ただし10/31で下方修正が出れば引き下げる</span> |
| 行動 | <span class="t-blue">三分割。第2弾は10/31の2Qで上期経常21.5億円を確認できたら。撤退基準を6項目、事前に定義済み</span> |
| <strong>損出し</strong> | <span class="t-green">保有継続と両立できる。信用の買建玉は現物の平均単価に混ざらないため、同日に現物売り＋信用買建でクロスすれば1日分の価格変動リスクを負わずに損失を確定できる</span>。<span class="t-red">ただし現引きは必ず翌営業日以降。NISAでは無意味</span> |
| <strong>損出しの使い道</strong> | <span class="t-blue">利益が厚い年ほど効く。作った枠でスライス利確・比率縮小・信用建玉の現引きを実質無税で進められる</span>。<span class="t-green">長く持つ銘柄なら取得単価の付け替えで簿価利回りが3.33%→3.82%へ</span>。<span class="t-red">ただし枠は売る理由にならない</span> |

> 💬 **守田より**
> 「紹介した銘柄が下がったとき、書き手には二つの誘惑がある。<span class="t-red">一つは黙ってやり過ごすこと。もう一つは『市場が間違えている』と言い切ってしまうことだ。</span>——今日はどちらもやらなかった。<strong>堀は無傷だと確認できた。同時に、我々が置いた6つの前提のうち2つが明確に崩れたことも認めた。数値の丸め方が楽観に偏っていたことも、下値論拠の一つが弱かったことも書いた。</strong><span class="t-blue">そのうえで、ランクはA−で据え置いた</span>。前提が崩れたのに格下げしないのは矛盾に見えるかもしれないが、これは矛盾ではない。<span class="t-green">我々のランクは会社の良し悪しではなく、いまの価格で買ったときの期待値に付いている。価格が価値より速く下がれば、悪いニュースの後でも妙味は増す</span>。ただし——<strong>それは会社予想が達成されるという前提の上にある。だから一括では買わず、10月31日を判定日に置いた。そして『何が起きたら降りるか』を、含み損で目が曇る前に書いておいた。</strong>投資記録というのは、当たった話より、こういう回のほうが後で効いてくる」
