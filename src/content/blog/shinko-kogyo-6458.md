## 🦞 先に釘を刺す｜「含み益で実質PBR0.5倍」という話ではない

🦞**守田**「リスク番だ。<span class="t-red">ここで気持ちよくなる前に、必ず潰しておくべき誤解がある</span>」

🦞**守田**「<span class="t-amber">投資有価証券230億円には、たしかに174億円の含み益がある。推定取得原価は約56億円で、含み益率は+312%だ</span>。<strong>だが、これは簿外資産ではない</strong>」

> ⚠️ **「隠れ含み益」ではない理由**
> ・その他有価証券は日本基準で<strong>時価評価される</strong>。値上がり分は「その他有価証券評価差額金」として純資産に入る
> ・<span class="t-red">つまり174億円は、すでにBPS 974.94円に織り込み済み</span>
> ・<strong>土地も1998〜2002年の再評価法で洗い替え済み</strong>。しかも土地再評価差額金は<span class="t-red">マイナス7.48億円＝評価損</span>
> ・主要拠点は秦野・津山・寝屋川という地方・郊外の工場用地で、地価上昇の恩恵は薄い
> ・<strong>修正BPSは約996円、修正PBRは1.24倍</strong>——<span class="t-amber">解散価値では、割安ではない</span>

🦞**守田**「<span class="t-red">『PBR1.27倍だが実は含み益で実質PBR0.5倍』という物語は、この銘柄では成立しない</span>。<strong>そこを期待して入ると失望する</strong>」

🦦**河内**「そのうえで、<span class="t-green">価値の源泉は含み益の“存在”ではなく、その扱い方のほうにあります</span>。<strong>取得原価56億円の資産が230億円に育っていて、会社は有報で『合理的理由がある場合を除き売却を進める方針』と明記している</strong>。<span class="t-blue">売却すれば税引後で約177億円——時価総額の22%が現金化されます</span>」

## まとめ｜「バリュー投資」ではなく「クオリティを妥当な価格で」

🧑‍💼**沼田**「今日の新晃工業を、一枚に畳む」

| 論点 | 結論 |
|---|---|
| 何が安いのか | <span class="t-green">時価総額831億のうち320億（38.5%）が金融資産。差し引き511億の事業EVに対し投下資本473億・税後ROIC14.7%＝1.08倍の評価。実質PER7.1倍・事業EV/EBIT5.1倍</span> |
| <strong>いま買う価格か</strong> | <span class="t-red"><strong>この水準では追わない。</strong>中立目標1,300円まで残り5.0%、リスク・リワードは1対0.4。<strong>1,190円以下まで待つ</strong></span> |
| 何が安くないのか | <span class="t-red">修正PBR1.19倍。有価証券の含み益174億はBPSに反映済み、土地は再評価法適用済みで差額金はマイナス7.48億。資産バリューでは割安ではない</span> |
| モート | <span class="t-blue">多品種少量の完全個別設計でスケール型が入れない。AMCA・AHRI認証は国内唯一。霞が関ビルを3度更新した納入実績が事実上のリカーリング権に</span> |
| 収益の心臓部 | <span class="t-green">工事子会社の新晃アトモスが経常利益率28.7%・ROA28%で連結経常の41%を稼ぐ。ボトルネックは需要ではなく施工人員</span> |
| ストック性 | <span class="t-green">工事52.6%＋ビル管理9.5%＝62.1%。機器販売も49.8%が更新需要。景気後退耐性が高い</span> |
| インカム | <span class="t-blue">利回り4.04%。配当性向50%目安＋DOE3.5%下限で、実績DOE5.4%は床から遠い＝減配リスクは低い</span> |
| 逆風 | <span class="t-red">1Q営業▲29.1%。そして2年で93億円買った自社株買いが残枠7億で枯渇し、総還元性向117.4%→56.4%へ。需給の空白期間に入った</span> |
| 本命の触媒 | <span class="t-amber">2027年5月前後の次期中計。政策保有株230億＋中国107.8億＝時価総額の42%をどう配り直すか。M&A枠30億も手つかず</span> |
| 握り方 | <span class="t-red">準主力3〜5%を三分割。11月の2Q（上期営業28億）と次期中計が判定点。1,050円以下なら前倒し</span> |

> 💬 **沼田より**
> 「この銘柄を『バリュー株』と呼ぶと、たぶん間違える。<span class="t-red">含み益は簿外ではないし、土地に夢もない。PBR1.27倍は、額面どおり1.27倍だ。</span>——それでも私が面白いと思うのは、<span class="t-green">時価総額の38.5%を占める現金と株を脇に置いたあと、残った511億円で買えるものの中身</span>だ。<strong>資本コストの2倍を稼ぐ事業が、投下資本とほぼ同額で売られている。売上の6割はストックで、工事子会社は経常利益率28.7%を叩き出している。これは『安い会社』ではなく『妥当な値段の良い会社』だ。</strong><span class="t-blue">そして本当の上値は、事業の外にある</span>。<strong>政策保有株230億円と、利益を生んでいない中国の107億円。合わせて時価総額の42%が、いま眠っている。</strong>次の中計で経営陣がそこに手をつけるなら、ROEは11%から15%へ動く。<span class="t-amber">2年で93億円を買い戻し、転換社債まで使ってバランスシートを組み替えてきた経営陣だ。その延長線上に賭ける価値はあると思っている</span>——ただし、急ぐ必要はまったくない」
