## 総況｜どちらも上昇、どちらも『まだまだ安い』

🧑‍💼**沼田**「まず全体像だ。2銘柄とも紹介時から上昇し、含み益が乗っている。だが結論から言えば、<span class="t-green">どちらもまだまだ安い。基本はホールド継続</span>だ」

| | 現在株価 | 平均取得単価 | 損益率 | 保有株数 | 現況ランク |
|---|---|---|---|---|---|
| 北里コーポレーション | **1,350円** | 1,181円 | <span class="t-green">**+14.3%**</span> | 3,400株 | <span class="t-blue">A−→**A**（引き上げ）</span> |
| 神栄 | **2,222円** | 2,100円 | <span class="t-green">+5.8%</span> | 2,400株 | <span class="t-blue">A→**A−**（改定）</span> |

🦉**夜見**「損益を積み上げます。<span class="t-green">確定益 約15.9万円（北里1,000株分）＋含み益 約86.7万円（北里 約57.5万＋神栄 約29.3万）＝合計 約103万円</span>。前回のSaaS組（約120万円）と合わせて、紹介銘柄のフォローとしては順調な部類です」

🦞**守田**「ただし前回と同じ釘を刺しておく。<span class="t-amber">上がってきた——それ自体は評価の理由にならない</span>。うちが見るのは常に"その株価で持つ妙味"だ。上がってなお安いのか、上がって安さが薄れたのか。今回の2銘柄は、その判定がちょうど逆に出た好例だ」

---

## 北里コーポレーション（368A）｜1,000株利確して、ランクはA−→Aへ"引き上げ"

🦉**夜見**「まず北里」

| 項目 | 数値 |
|---|---|
| 現在株価 | **1,350円**（紹介時1,206円→<span class="t-green">+11.9%</span>） |
| 平均取得単価 | **1,181円**（損益率<span class="t-green">+14.3%</span>） |
| 保有株数 | **3,400株**（当初4,400株） |
| 実現した売買 | <span class="t-green">1,000株を1,340円で売却＝確定益 約15.9万円</span>（PFバランス調整） |
| 含み益 | 約57.5万円（3,400株） |
| 現況ランク | <span class="t-blue">**A− → A に引き上げ**</span> |

🦫**堀田**「中身の確認から。<span class="t-green">生殖医療消耗品を110ヵ国で独占供給する構造も、[少子化対策マネーの"関所"というポジション](/blog/hidden-policy-stock-kitazato/)も、何も揺らいでいない</span>。株価は1割強上がったが、稼ぐ力と独占の確度に照らせば<strong>まだ明確に安い</strong>。上場来最低圏から抜け出しつつある局面で、妙味はむしろ濃いと再評価——ランクはAへ引き上げだ」

🦎**日向（見習い）**「え、ちょっと待ってください。<span class="t-amber">ランクを上げたのに、1,000株も売ったんすか?</span> 逆じゃないんすか?」

🧑‍💼「日向、いい質問だ。これが今回いちばん伝えたいことだ。<span class="t-blue">ランクは"この銘柄の妙味"の評価。ロットは"PF全体の中での資金配分"の話。別物なんだ</span>。北里は当初4,400株——取得ベースで500万円超と、うちのPFの中で膨らみすぎていた。だから<strong>妙味の評価とは無関係に、PFバランス調整として1,000株を1,340円で外した</strong>。評価はA、むしろ上げている。<span class="t-green">今後も上昇局面では、バランス調整で売ることはあるかもしれない</span>——だがそれは弱気転換ではない。3,400株の主力は、まだまだ安い間はしっかりホールドする」

---

## 神栄（3004）｜ランクはA→A−へ改定、でも1株も売らない

🦉「次に神栄」

| 項目 | 数値 |
|---|---|
| 現在株価 | **2,222円**（紹介時2,112円→+5.2%） |
| 平均取得単価 | **2,100円**（損益率<span class="t-green">+5.8%</span>） |
| 保有株数 | **2,400株**（当初から変わらずフルホールド） |
| 実現した売買 | なし |
| 含み益 | 約29.3万円 |
| 現況ランク | <span class="t-blue">**A → A− に改定**</span> |

🦦**河内**「神栄は資産バリューの主力格。<span class="t-amber">株価が上がってきた分、割安度がわずかに薄まった——それを正直にランクへ反映してA−</span>です。ただ、ここが大事なところで……<span class="t-green">A−はうちのルールでは"買い増し〜厚めにホールド"の帯。そして神栄は、資産の裏付けに対してまだまだ安い</span>。だから<strong>売りは検討すらしていません</strong>。2,400株、動かさずフルホールドです」

🦎「こっちはランクを下げたのに、売らないんすね……あ、そうか。<span class="t-blue">2,400株がいまのPFの中でちょうどいいロットだから</span>、ってことっすか」

🧑‍💼「その通り。北里と神栄、やっていることは逆に見えて、<span class="t-green">"ランクに応じた適正ロットへ整える"という同じ一つの作法</span>に従っているだけだ。北里は膨らみすぎたから削って適正へ、神栄は最初から適正だから触らない。<strong>売った・売らないの表面ではなく、ランクとロットの対応を見てほしい</strong>」

---

## まとめ｜『上がったから売る』でも『下がったから買う』でもなく

🧑‍💼「第二弾の整理だ」

| 論点 | 現況 |
|---|---|
| 損益 | <span class="t-green">確定益＋含み益で約103万円</span>（シリーズ累計 約223万円） |
| 共通認識 | どちらも上昇したが<span class="t-green">まだまだ安い＝ホールド継続</span> |
| 北里 | <strong>A−→A引き上げ</strong>。PF調整で1,000株利確済み・上昇局面では再調整の可能性あり |
| 神栄 | <strong>A→A−改定</strong>。それでも十分安く、<span class="t-blue">売りは検討していない</span> |
| 作法 | ランク＝妙味の評価／ロット＝資金管理。<span class="t-amber">両者は独立に判断する</span> |

> 💬 **沼田課長より**
> 「今回の2銘柄は、[前回](/blog/holdings-status-01-saas/)に書いたルール——<span class="t-blue">『ランクは株価に応じて定期改定し、ロットはランクに応じて整える』</span>——の生きた実例だ。ランクを上げた北里を一部売ったのは、PFの中で膨らみすぎた分を整えただけ。ランクを下げた神栄を売らないのは、A−がまだ十分な妙味の帯で、ロットも適正だからだ。<span class="t-green">『上がったから売る』でも『下がったから買う』でもない。妙味の濃さと資金の置き場所を、いつも対応させておく</span>——地味だが、これが生き残るための作法だと思っている。次回の現況報告も、できるだけ正直にやる」
