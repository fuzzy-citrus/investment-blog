## 総況｜土地の時価と株価の乖離に、PFの主力を張っている

🧑‍💼**沼田**「まず全体像。主力の2銘柄は<span class="t-blue">『昭和簿価の不動産に眠る含み益が、時価総額に対して桁違いに大きい』</span>という同じ型で、うちのPFの大黒柱だ。同型のサブ枠として京阪も少しだけ持っている」

| | 現在株価 | 平均取得単価 | 損益率 | 保有株数 | 現況ランク |
|---|---|---|---|---|---|
| 広済堂HD（信用枠） | **548円** | 497円 | <span class="t-green">**+10.3%**</span> | 10,000株 | <span class="t-blue">A++→**A+**</span> |
| 広済堂HD（現物枠） | **548円** | 516円 | <span class="t-green">+6.2%</span> | 7,300株 | 〃 |
| 東部ネットワーク（現物） | **1,317円** | 1,216円 | <span class="t-green">**+8.3%**</span> | **27,500株** | <span class="t-blue">A+→**A++**（格上げ）</span> |
| 京阪HD（サブ枠・現物） | **3,238円** | 3,090円 | <span class="t-green">+4.8%</span> | 300株 | B（据え置き） |

🦉**夜見**「損益とロットを積み上げます。含み益は<span class="t-green">広済堂 約74.4万円（信用51万＋現物23.4万）＋東部 約277.8万円＋京阪 約4.4万円＝合計 約357万円</span>。シリーズ累計では約558万円です。そしてロット——取得ベースで広済堂が約870万円、東部は<strong>約3,340万円</strong>。<span class="t-blue">この2銘柄でPFの主力を占める、文字どおりの大玉</span>です（京阪は約93万円のサブ枠）」

🦞**守田**「リスク番として最初に言っておく。<span class="t-amber">集中は"読みが当たれば大きく、外れれば痛い"を丸ごと引き受ける行為</span>だ。うちがそれでも張るのは、下値が資産（不動産含み益・現物中心）に守られ、上値の余地が大きいと判断しているからで——この判断自体を、こうして定期的に晒して点検する。それがせめてもの規律だ」

🧑‍💼「方針も先に明確にしておく。<span class="t-green">上昇に応じて保有数を減らす可能性はある。ただ、潜在的な上値がかなり大きい以上、ロット多めの保有は継続する予定</span>だ」

## 広済堂HD（7868）｜まだまだ安い。だがA++→A+へ——『優先順位』の話

🦉**夜見**「まず広済堂」

| 項目 | 数値 |
|---|---|
| 現在株価 | **548円**（紹介時521円→<span class="t-green">+5.2%</span>） |
| 信用枠 | 取得497円×10,000株（<span class="t-green">+10.3%</span>・含み益 約51万円） |
| 現物枠 | 取得516円×7,300株（<span class="t-green">+6.2%</span>・含み益 約23.4万円） |
| 含み益合計 | <span class="t-green">約74.4万円</span> |
| 現況ランク | <span class="t-blue">**A++ → A+ に引き下げ**</span> |

🧓**野村**「ふらっと来たぞ。信用枠の1万株はワシの流儀じゃな。<span class="t-blue">[買い方金利1.69%](/blog/nomura-margin-rate-1-69-alchemy/)を払ってでも、資産の裏付けがある大玉を先回りで押さえる</span>——下値が土地に守られとる銘柄なら、レバレッジは博打ではなく設計になる。ま、詳しくはワシの記事を読め」

🦎**日向（見習い）**「でも課長、広済堂って550円を割ってるんすよね? 中身の評価（NAV1,021円・火葬場の独占）は変わってないなら、むしろ買い場じゃ……なんでA++からA+に下げるんすか?」

🧑‍💼「中身の評価は変わっていない。<span class="t-green">548円はまだまだ安い——期待株価900円に対して+64%の余地がある</span>。下げた理由は——<strong>相対比較</strong>だ、日向。同じ『不動産含み益リッチ』の籠の中で、いま新しい資金を入れるならどちらが得か。<span class="t-blue">東部は1,317円まで来てなお、期待株価3,212円に対して+144%の乖離が残っている</span>。妙味の"濃さ"を並べたとき、序列が入れ替わった。だからA++の席を東部に譲る。<strong>広済堂が550円以下の買える水準にある今でも、優先的に集めるのは東部の方</strong>——という優先順位を、ランクで表現した」

🦦**河内**「A+は依然として"積極的に買い集める"帯です。<span class="t-amber">売る話ではまったくない</span>。1万7,300株はホールド継続、上昇局面でPFバランス調整の減量がありうる——という、いつもの作法どおりです」

## 東部ネットワーク（9036）｜走り始めて、なお安すぎる。A++へ格上げ、売りは検討せず

🦉「そして主力中の主力、東部」

| 項目 | 数値 |
|---|---|
| 現在株価 | **1,317円**（紹介時1,203円→<span class="t-green">+9.5%</span>） |
| 平均取得単価 | **1,216円**（すべて現物・損益率<span class="t-green">+8.3%</span>） |
| 保有株数 | <strong>27,500株</strong>（取得ベース約3,340万円＝PF最大ポジション） |
| 含み益 | <span class="t-green">約277.8万円</span> |
| 現況ランク | <span class="t-blue">**A+ → A++ に格上げ**</span>・<span class="t-green">売りは検討せず</span> |

🦦**河内**「株価は1割近く動き始めました。水準訂正の"初動"かもしれない。でも格上げの理由はそこじゃありません。<span class="t-red">1,317円まで来てなお、安すぎるまま放置されている</span>からです。昭和簿価の土地・物流不動産の含み益に対して、期待株価3,212円との乖離は<span class="t-green">まだ+144%</span>。走り始めてもゴールまでの距離がまるで縮まっていない——なら、うちの尺度では最上位のA++です」

🐊**待伏**「そして、ここからは待ち伏せ担当の"読み"です。この安すぎ放置は、いつまでも続かない。<span class="t-green">遅かれ早かれ、大株主の丸全昭和運輸による買収、もしくは経営陣による買収（MBO）が発生する可能性が高い</span>と判断しています。仮にそれが来なくても——<span class="t-blue">優待新設や特大増配といった株主還元イベントで、水準訂正が起きる</span>。どちらのルートでも、行き先は"是正"です」

🦞**守田**「待伏の読みに、リスク番として注釈を付ける。<span class="t-amber">買収も水準訂正も"判断"であって、約束ではない。時期は読めない</span>。だからこの張り方が許されるのは、①すべて現物で期限がないこと、②待っている間も資産の裏付けが下値を支えること——この2条件があるからだ。<strong>読みが遅れても退場しない形で待つ</strong>。それが大玉の最低条件だな」

🧑‍💼「結論、東部は<span class="t-green">2万7,500株、1株も売らずにホールド継続</span>。むしろ広済堂より優先して集めていく側だ」

## まとめ｜大玉は『減らせる形』で持ち続ける

🧑‍💼「第三弾の整理だ」

| 論点 | 現況 |
|---|---|
| 損益 | <span class="t-green">含み益 約357万円</span>（シリーズ累計 約558万円） |
| ポジション | 広済堂1万7,300株＋東部2万7,500株＝<span class="t-blue">PFの主力・ロットは他銘柄より桁違いに多い</span>（京阪300株はサブ） |
| 方針 | 上昇に応じて減らす可能性はあるが、<span class="t-green">潜在上値が大きいためロット多め継続</span> |
| 広済堂 | <strong>A++→A+</strong>。548円はまだまだ安い（期待900円比+64%）が、新規資金の優先は東部（550円以下でも東部優先） |
| 東部 | <strong>A+→A++格上げ</strong>・売り検討せず。期待3,212円比+144%の乖離。丸全昭和/経営陣の買収、または優待新設・特大増配での水準訂正を待つ |
| 京阪 | B据え置き・300株のサブ枠を静かに継続 |

> 💬 **沼田課長より**
> 「主力の2銘柄は、どちらも『土地の時価と株価の乖離』という同じ歪みに張っている。<span class="t-green">広済堂は期待値まで+64%、東部は走り始めてなお+144%。中身が同じくらい堅いなら、ゴールまで遠い方を上に置く</span>——A++の席替えは、それだけの話だ。大玉で持つ以上、守りの条件は崩さない。現物中心・下値は資産・信用は[金利1.69%の設計](/blog/nomura-margin-rate-1-69-alchemy/)の範囲で。そのうえで、買収か、還元か、水準訂正か——<span class="t-blue">どのルートで是正が来ても受け取れる場所に、多めの資金を置いて待つ</span>。潜在的な上値の大きさが、待つ時間の対価だ。次回もできるだけ正直に報告する」
