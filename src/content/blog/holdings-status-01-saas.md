> 🧑‍💼 「紹介した銘柄は、紹介して終わりではなく——<span class="t-green">その後どうなったかも、できるだけフォローして伝えていきたい</span>。買った値段、今の値段、売った株数、残した株数、そして"今いくらの評価か"まで、できる範囲で正直に。今日からそういうシリーズを始める。第一弾は、あの『SaaSは死んだ』騒ぎのド底で拾いにいったIT系2銘柄だ」

## このシリーズについて｜ランクは"生き物"、だから定期的に改定する

🧑‍💼**沼田**「最初に、このシリーズの約束事を言っておく。うちの現況ランク（A++〜B）は<span class="t-blue">"その株価で買う・持つ妙味"の評価</span>だ。ということは——<strong>株価が動けば、割安度も動く。だからランクも動く</strong>。紹介時のランクを金科玉条にせず、定期的に現況を点検して改定していく」

> 💡 **バリュー商会のランク運用ルール（全公開）**
>
> ・<span class="t-green">**A+以上** … 積極的に買い集める</span>
> ・**A／A−** … 買い増し〜厚めにホールド
> ・**B帯（B−以上）** … 取得・保有の妙味あり。ランクに応じてロットを調整しながらホールド
> ・<span class="t-red">妙味ラインはB−</span>。これを割る評価になれば新規は見送り、縮小・売却を検討
> ・**一部売却はあくまで資金管理（PFバランス調整）の一環**＝弱気転換ではない。<span class="t-amber">割安が解消されれば全売却も検討</span>

🦞**守田**「補足すると、この"ロット調整"が肝だ。<span class="t-blue">ランクが上がれば張りを厚く、下がれば薄く</span>。売り買いを当てにいくのではなく、<strong>妙味の濃さに応じて資金の置き場所を動かす</strong>——[資金管理](/blog/capital-management-survival/)の続きだと思ってくれ」

## 総況｜『SaaSは死んだ』の底値買いは、おおむね利益に

🧑‍💼「さて第一弾はIT系。[『SaaSは本当に死んだのか?』](/blog/saas-death-japan-it/)で書いたとおり、市場がソフトウェア株を一括で叩き売った歪みに乗じて、うちは<span class="t-green">"深いIT"2銘柄——[日鉄ソリューションズ（2327）](/blog/nssol-2327/)と[菱友システムズ（4685）](/blog/ryoyu-systems-4685/)</span>を仕込んだ。現況はこうだ」

| | 現在株価 | 平均取得単価 | 損益率 | 保有株数 | 評価 |
|---|---|---|---|---|---|
| 日鉄ソリューションズ | **3,775円** | 3,279円 | <span class="t-green">**+15.1%**</span> | 1,100株 | <span class="t-blue">A→**B++**</span> |
| 菱友システムズ | **2,929円** | 2,840円 | <span class="t-green">+3.1%</span> | 2,400株 | <span class="t-blue">A→**A−**</span> |

🦉**夜見**「損益を積み上げます。<span class="t-green">確定益 約44.6万円（NSSOL 900株分）＋含み益 約76万円（NSSOL 54.6万＋菱友 21.4万）＝合計 約120万円</span>。おおむね利益が出ている状態です」

🦎**日向（見習い）**「120万! 底も打ったんすよね!? じゃあもう全力で買い増し……」

🦞**守田**「日向、まだだ。<span class="t-amber">売られすぎの大底は"打ったように見える"——そこまでしか言えない</span>。油断できる状況ではない。<strong>もう一度底を試しに来るようなら、そこは買い増しを検討する場面</strong>だし、逆にこのまま上がるなら、段階的な一部売却を都度検討しながら<span class="t-blue">割安解消まで一定数はホールド</span>——どちらに転んでも作法どおりに動くだけだ」

## 日鉄ソリューションズ（2327）｜900株を利確、A→B++へ

🦉**夜見**「個別に見ます。まずNSSOL」

| 項目 | 数値 |
|---|---|
| 現在株価 | **3,775円**（紹介時3,423円→<span class="t-green">+10.3%</span>） |
| 平均取得単価 | **3,279円**（損益率<span class="t-green">+15.1%</span>） |
| 保有株数 | **1,100株**（当初2,000株） |
| 実現した売買 | <span class="t-green">900株を3,775円で売却＝確定益 約44.6万円</span> |
| 含み益 | 約54.6万円（1,100株） |
| 現況ランク | <span class="t-blue">**A → B++ に改定**</span> |

🐊**待伏**「3D Investment Partnersの外圧・防衛策消滅というイベントの筋は、今も生きています。ただ——<span class="t-amber">株価が1割上がった分、"安さの余白"は素直に薄くなった</span>。稼ぐ力対比のディスカウントが縮んだ以上、ランクはAからB++へ下げるのが、うちのルールに忠実な判断です」

🧑‍💼「900株の売却は、<strong>利食いではなくPFのバランス調整</strong>だ。2,000株はこの銘柄の現在の妙味（B++）に対して張りすぎ——だから適正ロットへ戻した。<span class="t-blue">残り1,100株のうち1,000株程度は、割安解消（もしくはイベント決着）までホールドする予定</span>だ。B++はまだ十分"保有妙味あり"の水準だからな」

## 菱友システムズ（4685）｜まだ安い、買い増してA→A−へ

🦉「次に菱友」

| 項目 | 数値 |
|---|---|
| 現在株価 | **2,929円**（紹介時2,896円→+1.1%） |
| 平均取得単価 | **2,840円**（損益率<span class="t-green">+3.1%</span>） |
| 保有株数 | **2,400株**（当初2,000株） |
| 実現した売買 | <span class="t-green">400株を2,830円で追加取得</span>（PFバランス調整） |
| 含み益 | 約21.4万円 |
| 現況ランク | <span class="t-blue">**A → A− に改定**</span> |

🦫**堀田**「防衛・宇宙ITの準独占という中身は何も変わっていない。株価がわずかに上がって割安度が"ほんの少し"薄まった——それを正直にランクへ反映してA−。<span class="t-green">それでもまだ明確に安い。だからこちらは売らない。買い増し目線を維持する</span>」

🧑‍💼「動くとすれば上だ。<span class="t-blue">3,260円程度まで上がれば、PFのバランス調整として一部売却を検討する</span>。逆にここから売られる局面があれば、A−の妙味に対してロットを厚くするチャンスと見る」

🦎**日向**「あれ、NSSOLは売って、菱友は買い増し……同じSaaS底値買いなのに、逆のことしてるんすね?」

🧑‍💼「そこがこのシリーズで一番伝えたいことだ、日向。<span class="t-green">2銘柄の"妙味の濃さ"が変わったから、資金の置き場所を変えた——それだけ</span>。NSSOLは+10%上がって妙味が薄まり（B++）、菱友はほぼ動かず妙味が濃いまま（A−）。なら<strong>薄くなった方から濃い方へ資金を寄せる</strong>。売った・買ったに意味があるんじゃない。<span class="t-blue">ランクとロットの対応を守ること</span>に意味がある」

## まとめ｜"当てる"より"整える"

🧑‍💼「現況を整理する」

| 論点 | 現況 |
|---|---|
| 損益 | <span class="t-green">確定益＋含み益で約120万円</span>＝おおむね利益 |
| 相場観 | 売られすぎの大底は打ったように"見える"が、<span class="t-amber">油断はしない</span> |
| 下に行けば | <span class="t-green">底を試すなら買い増しを検討</span>（特に菱友） |
| 上に行けば | 段階的な一部売却を都度検討しつつ、<span class="t-blue">割安解消まで一定数ホールド</span> |
| ランク改定 | NSSOL <strong>A→B++</strong>（+10%で割安度縮小・900株利確）／菱友 <strong>A→A−</strong>（まだ安い・買い増し） |

> 💬 **沼田課長より**
> 「一部売却は、勝ち逃げでも弱気でもない。<span class="t-blue">資金管理の一環</span>だ。割安が解消されれば全売却も検討するし、株価が下がって妙味が戻れば、また厚くする。<span class="t-green">現在株価が変われば割安度が変わる。だから現況ランクは定期的に改定するし、ランクに応じてロットを調整する。B−以上は妙味あり、A+以上は積極的に買い集める</span>——この当たり前を、実際の損益と株数を晒しながら続けていく。当てにいくな、整えにいけ。次回の現況報告も、この調子で正直にやる」
