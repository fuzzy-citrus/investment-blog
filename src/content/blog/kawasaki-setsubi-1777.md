## まとめ｜物差しを持ち替えるという判断

🧑‍💼**沼田**「今日の話を、一枚に畳む」

| 当てた物差し | 結果 |
|---|---|
| 土地の含み益 | <span class="t-red">空振り</span>。全社2,094坪、税引後46円/株＝<strong>株価の2.0%</strong> |
| 有価証券の簿外含み益 | <span class="t-red">空振り</span>。すでに時価評価済みで<strong>簿外はゼロ</strong> |
| ネットキャッシュ | <span class="t-red">空振り</span>。期末29.5億円＝<strong>時価総額の10.6%</strong> |
| 下値の床 | <span class="t-red">空振り</span>。PBR1.72倍・修正PBR1.66倍で<strong>床が無い</strong> |
| <strong>収益力</strong> | <span class="t-green"><strong>命中</strong>。営業利益率13.0%（大手5社中2位）・ROE24.8%（全社中1位）でPER8.15倍</span> |
